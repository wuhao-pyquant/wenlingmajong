# Photon 登录核心舞台设计

## 目标

移除登录页左侧的全部宣传文字，把原区域完整交给现有的发白麻将 Photon 核心展示。顶部“温岭麻将”品牌和 `SYSTEM ONLINE` 状态保留，登录、注册、会话和导航功能保持不变。

## 范围

- 仅修改 `/battle-login` 的布局和 Photon 核心在登录页的位置。
- 不修改 `/battle-lobby` 的房间大厅布局或核心位置。
- 不修改 `/battle`、牌局逻辑、账号接口、房间接口或本地存储键。

## 页面结构

删除 `.photon-auth-copy` 及以下文字：

- `PHOTON GAME NETWORK`
- `连接牌桌`
- `进入对局`
- `温岭好友牌局 · ONLINE`

在原位置使用空的 `.photon-auth-visual` 作为无文字视觉舞台。它只负责稳定布局和为背景核心留出无遮挡区域，不显示卡片、说明或装饰文字，并设置 `aria-hidden="true"`。

## 响应式布局

### 桌面

登录舞台继续使用两列布局：左侧视觉舞台占主要空间，右侧认证控制台保持靠下。Photon 麻将核心移动到左侧视觉舞台中央，避免被认证控制台遮挡。

### 手机竖屏

`440 x 956` 及同类窄屏使用三段结构：顶部导航、中央视觉舞台、底部认证控制台。视觉舞台使用稳定的最小高度和弹性剩余空间，核心位于导航和控制台之间；认证控制台不因删除文字而上移占据核心区域。

### 低高度横屏

视觉舞台缩小但不消失，认证控制台继续允许内部滚动。页面不得产生横向溢出，核心不得遮挡输入框和按钮。

## Photon 场景

现有粒子、连线、灯光、质量降级和生命周期保持不变。只调整登录页麻将牌组的位置：

- 桌面登录页：移到左侧视觉舞台中心。
- 手机登录页：移到页面中央偏上，位于导航与控制台之间。
- 房间大厅：保持现有位置。

Three.js 不可用时继续使用 Canvas 或静态降级，不引入新的远程资源。

## 缓存与部署

登录页 HTML、Photon CSS 和 Photon 场景脚本发生变化后，登录页与大厅页的统一资源版本提升到新的缓存令牌，避免 NAS 或手机继续使用旧文件。
